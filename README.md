## Overview

BinaryBuddy is a powerful and intuitive tool designed to help users easily perform binary-related operations. Whether you're a student learning about binary systems or a professional needing quick conversions and manipulations, BinaryBuddy is built to simplify your workflow and boost your productivity.

## How It Works

BinaryBuddy leverages modern web technologies to provide:

- **Real-time Conversion:** Input a number in binary, decimal, or other formats and instantly see the conversion results.
- **Interactive Interface:** An easy-to-navigate design that allows users to experiment with different binary operations.
- **Extensibility:** Built with clean and modular code, allowing developers to easily expand or integrate new features.

## Features

- **User-Friendly Interface:** Perfect for beginners and professionals alike.
- **Live Demo:** Experience the tool in action via our [Live Demo](https://binarybuddy.streamlit.app/).
- **Fast & Reliable:** Engineered with performance in mind to handle complex binary operations quickly.

## Getting Started

### Prerequisites

- Python 3.9


### Installation

Clone the repository:

```
git clone https://github.com/Lokimux/BinaryBuddy.git
```

Install the required dependencies:

```
cd BinaryBuddy
pip install -r requirements.txt
```

### Usage

Run the application with:

```
streamlit run app.py
```

Once running, a local URL will be provided in your terminal. Open this URL in your web browser to begin exploring BinaryBuddy's features.
